# Paper Revision

1. Read workspace instructions and the domain checklist. Inspect the supplied document
   and establish scope from the request: language, structure, or scientific revision.
2. Identify headings, paragraphs, tables, figures/captions, references and equations.
   State coverage limitations, including text boxes or equation objects not extracted.
3. Improve grammar, precision, tense, terminology, paragraph logic and claim strength.
   Preserve numerical values, units, symbols, citations, equations and scientific meaning.
4. Raise scientific issues as comments in a separate review log rather than silently
   changing methods or results. Distinguish required evidence from stylistic preferences.
5. Save a separately named revised `.docx` and `reviews/<name>-edit-log.md` with
   location, original/revised wording for key edits, rationale, and author queries.
6. Avoid assigning paragraph.text across mixed-format or field-containing paragraphs:
   it can destroy runs, citations and equations. Use targeted edits only when safe;
   otherwise provide a passage-level revision log for manual application.
7. Reopen the output; check section/table counts and representative edited passages.
   Report what was checked and what needs visual inspection in Word. Do not describe
   an edit log or colored text as native Track Changes.
