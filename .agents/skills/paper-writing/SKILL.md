# Paper Writing

1. Read the workspace instructions and `references/domain-checklist.md`.
2. Inspect supplied documents, data, and verified references. Infer the requested section
   and journal constraints; ask only for facts needed to avoid inventing scientific content.
3. Build a claim-evidence outline covering the problem, literature gap, objective,
   methods, results, discussion, limitations and conclusions. Mark missing evidence.
4. Draft clear academic English. Distinguish supplied results from proposed work;
   use explicit placeholders for missing results/citations. Do not invent novelty.
5. For a complete manuscript, include title, abstract, keywords, nomenclature where useful,
   introduction, methods, results, discussion and conclusions; adapt to journal rules.
6. If producing Word, use python-docx, preserve source files, and write a separate `.docx`.
   Keep equations and citations intact; flag unsupported complex Word elements.
7. Deliver the requested draft plus a concise list of unresolved scientific inputs.
